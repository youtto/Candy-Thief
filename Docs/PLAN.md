# Six-week milestones (study weeks 3–8)
| Week | Scope | Done when |
|---|---|---|
| 3 | Unity baseline, player movement/collision, camera, title/HUD placeholders | Start → move in test room |
| 4 | Guard patrol, view cone, obstacle occlusion, detection/fail | Guard detects visible player, not through walls |
| 5 | Key/gold pickups, exit, clear/fail/retry | One full gameplay loop |
| 6 | One daytime shop map, NPC/shopper/art/UI integration | Level playable end to end |
| 7 | Difficulty tuning, bug fixes, optional local save | 3 clean consecutive playthroughs |
| 8 | WebGL build, browser QA, deploy, demo | Shareable playable URL |

## Scope control
P0: full loop + one guard + one map + WebGL. P1: shoppers, persistent record, animations, polish. P2: night/companions/gacha (post-MVP).
At end of each week, defer unfinished P1/P2 rather than slipping P0.
